# Portfolio Website — YasirLab

> The site itself — semantic HTML, responsive CSS, vanilla JS, no framework.

![HTML](https://img.shields.io/badge/HTML-5-E34F26) ![CSS](https://img.shields.io/badge/CSS-3-1572B6)

## Problem
Present 15 ML builds credibly across devices without build tooling.

## Approach
Semantic HTML, 12-col grid, `style.css` editorial system (Plus Jakarta Sans + JetBrains Mono), `script.js` vanilla, `file://` fallback, 4-nav structure (Home·About·Projects·Contact).

## Results
Lighthouse ~95+, responsive 320–1440px — see https://yasirlab.in

# Matplotlib Visualizer — Publication Charts

> Reproducible bar/line/scatter with consistent style.

![Matplotlib](https://img.shields.io/badge/Matplotlib-3.7%2B-11557c)

## Approach
`figure()` → `plot/bar/scatter` → `savefig("results/*.png", dpi=150)` — `pathlib.Path("results").mkdir`.

## Quick start
```bash
pip install -r requirements.txt
python src/charts.py
# results/line.png, bar.png, scatter.png
```

## Structure
```
matplotlib-visualizer/src/charts.py
```
